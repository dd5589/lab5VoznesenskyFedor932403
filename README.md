# Портфолио фотографа — Лабораторная работа №5

## Задание (Вариант 11)

**Тема:** «Фотограф и визуальный сторителлер» (галерея снимков с подписями).

**Цель:** научиться манипулировать DOM-деревом, находить элементы, изменять содержимое и стили, а также сохранять состояние страницы между перезагрузками через `localStorage`.

**Контент:** сетка изображений (заглушки-div, подпись `<figcaption>`).

**Инструменты:** DOM API, JS, `localStorage`.

## Реализация в `script.js`

- `getElementById` — поиск пяти ключевых элементов галереи (`#gallery`, `#add-photo-btn`, `#toggle-gallery-btn`, `#theme-toggle`, `#empty-gallery-msg`);
- `querySelector` — поиск только что добавленной карточки по `data-id` (для плавного скролла) и удаляемой карточки в `removeGalleryPhoto`;
- `querySelectorAll` — подсчёт всех `#gallery figcaption` после рендера;
- `createGalleryItem(photo)` — создание `<figure class="gallery-item">` с `div.gallery-thumb` (заглушка 🖼️, если URL пустой), `<img>` для реального URL и `<figcaption>` с подписью и кнопкой ✕;
- `renderGallery()` — очистка контейнера (`innerHTML = ''`) и вставка всех карточек через `appendChild`;
- `addGalleryPhoto()` — запрос URL и подписи через `prompt`, валидация URL через `new URL()`, сохранение и рендер;
- `removeGalleryPhoto(id)` — `findIndex` + `splice` для массива, `querySelector('[data-id=…]')` + `element.remove()` для DOM-элемента;
- `updateEmptyMessage()`, `updateThemeButton()`, `updateGalleryVisibility()` — обновление состояния интерфейса;
- `checkGalleryElements()` — проверка существования всех элементов, ранний `return` в `initGallery`, если чего-то нет;
- `try/catch` — вокруг каждого обращения к `localStorage` (сохранение и чтение фото, темы, видимости);
- `img.addEventListener('error', …)` — если картинка не загрузилась, `img.remove()` и откат к заглушке.

## Сохранение состояния в `localStorage`

- `portfolio_gallery_photos` — массив фото `[{ id, url, caption }]`;
- `portfolio_theme` — `'dark'` или `'light'`;
- `portfolio_gallery_visible` — `'true'` или `'false'`.

При загрузке страницы `loadGalleryState()` восстанавливает фото, тему и видимость; `initGallery()` перерисовывает галерею и навешивает обработчики.

# Портфолио фотографа — Лабораторная работа №4

## Задание (Вариант 11)

**Тема:** «Фотограф и визуальный сторителлер» (количество фото в день).

**Цель:** познакомиться с синтаксисом JS, базовыми конструкциями и логикой.

**Данные:** массив из 6 чисел — количество сделанных фото за день.

    const photos = [120, 200, 170, 420, 50, 220];

## Реализация в `script.js`

- `prompt` — ввод имени, `alert` — приветствие;
- `console.log` — вывод всей статистики;
- `sumArray(arr)` — сумма всех фото;
- `findMax(arr)` — максимальное количество фото за день;
- `filterHighActiv(arr, threshold)` — фильтрация дней с высокой активностью (строго `> 200`);
- `getLowActiv(arr, threshold)` — дни с малой активностью (`<= 50`);
- `calculateAverage(arr)` — среднее количество фото за день;
- цикл — подсчёт дней с малой активностью и их процента от общего количества;
- доп. условие — при максимуме `> 300` в консоль выводится мотивационное сообщение.

**Вывод:**
- `alert` — «Всего сделано Х фото, в Y днях активность была высокой»;
- `console.log` — максимум, среднее, дни высокой и низкой активности, количество и процент дней с малой активностью;
- `console.log` — доп. сообщение при максимуме `> 300`.
